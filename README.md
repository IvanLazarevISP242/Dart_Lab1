## ответы на вопросы
1. Статическая типизация — тип переменной известен на этапе компиляции. Главное отличие от Python: в Dart каждая переменная имеет тип, который
проверяется до запуска. Это означает, что целый класс ошибок компилятор поймает
заранее — вместо того чтобы упасть в рантайме.
2. ? разрешает null в переменной
3. Бывают значения, которые должны быть установлены один раз и больше не меняться.
В Python такого механизма нет — программист просто договаривается сам с собой.
В Dart для этого есть ключевое слово final:
final — значение присваивается один раз, но может быть вычислено во время
выполнения программы.
4. Во Flutter практически каждый виджет использует именованные
параметры. Без понимания этого синтаксиса код Flutter читать не получится. В Dart позиционные и именованные параметры — разные механизмы
([] vs {}), нельзя использовать одновременно для одного параметра.
